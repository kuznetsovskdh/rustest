# Скриншоты для README

Нужны три файла. Пока их нет, GitHub показывает на месте картинок иконки битых изображений.

| Файл | Страница | Аккаунт |
|---|---|---|
| `analytics.png` | http://localhost:3001/admin/product-analytics | админ |
| `test.png` | прохождение любого теста | ученик |
| `result.png` | экран результата с раскрытым правилом | ученик |

## Аккаунты

Для кадра с аналитикой нужен свой аккаунт с ролью `admin` — пароль сюда не выносим:

```sql
UPDATE users SET role='admin' WHERE email='ваш@email';
```

Демонстрационные аккаунты создаёт `scripts/seed_demo_data.py`, пароль у всех общий:

| Роль | Email | Пароль |
|---|---|---|
| Ученик | `student.<timestamp>.7@rustest.example.com` | `demo1234` |
| Преподаватель | `teacher.<timestamp>@rustest.example.com` | `demo1234` |

Точные адреса после засева:

```bash
docker exec rustest-postgres-rustest-1 psql -U rutest -d rutest \
  -c "select id, email, role from users where role='teacher' or email like 'student.%' limit 5;"
```

## Как снимать на macOS

`Cmd+Shift+4`, затем `Пробел`, затем клик по окну браузера — снимок окна без адресной строки, файл падает на рабочий стол.

Если у окна остаётся серая тень по краям, зажмите `Option` в момент клика — тень не попадёт в кадр.

## 1. analytics.png

Войти админом → «Админ» в шапке → «Product Analytics».

В кадр должны попасть **одновременно**:
- блок **Activation Funnel** — 4 шага, 78 → 62 → 42 → 8;
- таблица **Cohort Retention** — 6 строк когорт, слева проценты, справа прочерки.

Прочерки принципиальны: они показывают, что метрика отличает «неделя ещё не наступила» от «нулевой retention». Это то, что отличает работу от типового дашборда.

Оба блока идут подряд, но могут не влезть в экран — уменьшите масштаб браузера до 80 % через `Cmd+−`.

## 2. test.png

Войти учеником → «Каталог» → любой тест → «Начать тест».

В кадре: текст вопроса, варианты ответа и **работающий таймер** в правом верхнем углу карточки.

## 3. result.png

Дойти до конца теста, **специально ответив хотя бы на один вопрос неверно**. На экране результата найти карточку с пометкой «Ошибка» и нажать «Почитать правило».

В кадре: процент результата, карточка ошибки с блоком «Ваш ответ / Правильно» и раскрытый текст правила с примерами.

Без ошибки в кадре экран показывает только проценты — ни разбора, ни привязки к справочнику, то есть самой содержательной части.

## Куда положить

Переименовать файлы точно как в таблице выше и положить в эту папку:

```
docs/screenshots/analytics.png
docs/screenshots/test.png
docs/screenshots/result.png
```

Проверить, что README их видит, можно локально — в VS Code открыть README.md и нажать `Cmd+Shift+V` (предпросмотр).

## Требования

- Формат PNG, светлая тема интерфейса.
- Ширина 1400–1600 px для `analytics.png`, 900–1200 px для остальных: GitHub отдаёт README в колонке около 900 px, больше не нужно.
- Почты вида `student.*@rustest.example.com` — синтетика, скрывать не нужно.
